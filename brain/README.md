# [Company] GTM brain

Everything we know about who buys, why, how deals move, and what's working. The Autopull automations read and write here, and call AI Rob for the judgment.

- Start with `gtm/case-study.md` (who buys and why) and `gtm/sales-process.md` (how a deal moves).
- Each buyer has a folder in `deals/`, with the prep for every call, every review and every draft.
- `reports/` has the audit and every weekly review. `gtm/learnings.md` has what each week taught.
- `automations/settings.md` is where the schedule, drafts and "in the loop or not" live.
- The factory homepage: `cd factory && node server.js`, then open http://localhost:4747.

Private. This repo holds prospects and customers.
