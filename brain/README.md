# [Company] GTM brain

Everything we know about who buys, why, how deals move, and what's working. The GTM loops read and write here, and call AI Rob for the judgment.

- Start with `gtm/case-study.md` (who buys and why) and `gtm/sales-process.md` (how a deal moves).
- Each buyer has a folder in `deals/`.
- Each running loop has a folder in `loops/`.
- The factory homepage: `cd factory && node server.js`, then open http://localhost:4747.
