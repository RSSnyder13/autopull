# Loops

Each running loop gets a folder here the first time it runs, with:

- `settings.md`: when it runs, where it notifies the founder, and whether the founder wants to review changes first or have them applied and get notified.
- `changes.md`: every change the loop made or suggested, with what it expected to happen, and later whether it worked.
- `runs/YYYY-MM-DD.md`: what each run did and what it sent the founder.

A loop may add other files. Its `SKILL.md` says which.
